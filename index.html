SMAT quick guide

MATLAB-style workspace and examples

Arithmetic and comparison operators (including .*, ./, .^ and '), variables, ranges such as start:step:end, vectors and matrices with indexing, for / while / if blocks, common math functions, fprintf, and 2D line plots (hold on for several lines) are supported in this lightweight browser engine.

Example

x = 0:0.1:2*pi;
y = sin(x);
plot(x,y);
title("Sine wave");

The built-in browser engine is only a lightweight subset. The advanced examples (user functions, fzero, ode45, surf, complex numbers, and broader MATLAB syntax) require GNU Octave through the included local backend. GNU Octave is not identical to MATLAB and some proprietary toolboxes / Simulink features are unavailable. SMAT is an independent project, not MathWorks MATLAB.
